# Contact Cleaner

Turns a messy contact list into a clean, deduplicated one, plus a report showing exactly what changed and why.

## The problem

Contact lists built by different people are full of extra spaces, inconsistent formats, typos, placeholders like "N/A", and duplicate entries. Cleaning them by hand takes hours and misses things.

## What it does

- Trims spaces, fixes name capitalization, lowercases emails
- Converts every phone to one format: (713) 555-0123
- Treats placeholders like N/A, null, none and - as empty
- Rejects rows that can't be used (missing name, invalid email, no way to contact), with the reason for each
- Removes duplicates (same email or same phone, after cleaning) and keeps the most complete record
- Generates an HTML report with a before/after view of every change

## Example result

On the included sample file (40 messy contacts):

| Rows in | Clean rows | Duplicates removed | Rejected |
|---|---|---|---|
| 40 | 28 | 4 | 8 |

## How to run

Requires Python 3. No installs needed.

```
python cleaner.py sample_messy.csv
```

Results are saved in the `output/` folder:
- `contacts_clean.csv`: the clean contacts
- `contacts_rejected.csv`: rejected rows with original values and reasons
- `report.html`: the before/after report

## Known limitations

- Phone formatting supports US numbers only. Extensions (like x99) are treated as invalid
- Names like McDonald or O'Brien may not capitalize perfectly
- Company and city names are trimmed but not capitalized
- Input must have exactly these columns: name, email, phone, company, city

## How it was built

I wrote the specification (SPEC.md): every cleaning, rejection and duplicate rule. The code was generated by directing an AI coding agent (Cursor), then verified against hand-calculated expected results and edge-case tests (empty file, missing file).
